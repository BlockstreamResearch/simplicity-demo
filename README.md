# SimplicityHL Quickstart

This repository is a quickstart tutorial using a Rust project to help you perform your first transaction with SimplicityHL on Liquid Testnet.


You'll need [Rust installed](https://rust-lang.org/tools/install/) before you start.

Recommended instructions and explanations are available online at

https://docs.simplicity-lang.org/getting-started/quickstart



## Next steps

This project is based on the [simplicity-contracts](https://github.com/BlockstreamResearch/simplicity-contracts) repository, which includes more complex examples. As a next step, you can try out some of those contracts, or look at some [simpler examples demonstrating SimplicityHL language features](https://github.com/BlockstreamResearch/SimplicityHL/tree/master/examples).

You can also check out our [SimplicityHL documentation](https://docs.simplicity-langage.org/).
